# 微信预览读取旧素材

**范围**　2026-11-23，`ocean-shelter` 独立构建，Windows 微信开发者工具 Stable 1.06.2402030。

**现象**　模拟器可进入全船总览，点击「预览」提示 `ENOENT: no such file or directory`，缺失文件为 `dist/media/pixi-ui-probe.png`。

**定位**　当前目标清单、项目配置和 bundle 均无该旧路径，读取发生在预览的其他文件打包阶段。开发者工具历史日志曾记录该路径。重新打开项目、重置文件列表并清除编译缓存后，用户重试仍出现同一错误。定位到旧目录进入了预览打包文件列表，具体缓存来源未确定。

**修复**　在 `project.config.json` 的 `packOptions.ignore` 按目录排除废弃的 `dist/media`。已用安装版开发者工具的过滤逻辑检查该规则，`dist/resources/` 下的当前路径仍可进入打包。 [微信项目配置](../../project.config.json)

**验证**　当时用微信 CLI 执行一次已获授权的预览，成功生成二维码。这次预览早于主包与运行资源分离，验证范围是旧路径报错的修复和当时的游戏包生成。

**复发时**　先用报错中的相对路径对照 `scripts/targets.json`、当前 `dist/`、bundle 中的读取路径和 `packOptions`。如果路径是当前目标所需文件，修正资源声明或加载路径并重建。如果路径属于已废弃产物，检查预览文件列表与排除规则。以实际预览区分本地编译成功与打包成功。 [构建与验证流程](../AGENT_WORKFLOW.md#4-构建并验证)
